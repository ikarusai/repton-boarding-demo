# Repton crest

`repton-crest.png` is the unchanged 240 × 350 transparent white crest already supplied in the original `boarding-wellbeing.html` under the CSS custom property `--bw-crest`. It was extracted from that embedded PNG on 9 November 2026; it was not generated or redrawn.

The school is [Repton Dubai](https://www.reptondubai.org/). This asset retains the handoff's existing school identity. No new trademark license is asserted. The implementation preserves its aspect ratio and original white artwork, with decorative repeated copies hidden from assistive technology and school identification included in the header's accessible name.

The build embeds the image as a data URL in `repton-branding.mjs`; the running app makes no external logo requests. Keep this asset with the source package. School branding approval remains part of the normal school-side release review.
